# Support

Fugal Subnet is currently experimental and pre-launch.

- Use the [issue tracker](https://github.com/fugal-ai/fugal-subnet/issues) for reproducible bugs and scoped feature requests.
- Read the [Miner Guide](docs/MINER_GUIDE.md) and [Validator Guide](docs/VALIDATOR_GUIDE.md) before opening an operational issue.
- Include the commit SHA, Python and Bittensor versions, network, sanitized logs, and reproduction steps.
- Never post API keys, wallet mnemonics, private keys, or other credentials.
- Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

There is no guaranteed response time or production support commitment during the pre-launch phase.
